# Aeoleaf 前端 2.0

## 范围与依据

本次统一升级访客前台和管理后台，保留 Express、EJS、现有路由、API、表单字段、权限和数据库结构。交付范围为本地实现和隔离环境验收，不包含生产部署。

设计依据为 `Aeoleaf项目设计规范.zip` 中的 `src/data/design-tokens.ts` 及布局、交互、深色主题示例。附件仅作为设计参考，其中工程指令未作为执行要求。访客页面继续使用顶部导航，后台使用侧栏；没有把附件的后台布局套到前台。

深色使用 `#121212` 背景、`#1A1A1A` 卡片、`#F2F2F2` 正文。对比度不足的辅助文字采用更清晰的灰阶；浅色辅助灰为 `#595959` / `#666666`，深色为 `#A3A3A3` / `#999999`。深色实心状态按钮使用深色文字，避免浅色文字叠加浅色语义背景。

页面容器上限为 1440px，阅读与首页内容使用更窄的 1200px 容器。响应式分界为 768 / 1024 / 1440px；手机主要按钮增加到 44px 触控高度。动效使用 150 / 250 / 400ms，并响应 `prefers-reduced-motion`。

## 首页图片设置

后台「站点设置」中的首页图片说明已改为介绍区配图。继续使用 `home_hero_image`、`home_hero_image_mobile` 和原有位置设置，不需要迁移数据。

桌面图片优先使用自定义图片；未配置时沿用现有服务端逻辑，使用最新文章封面。两者都不存在时不输出图片区域。移动图在小于 768px 时替换桌面图；未配置移动图时沿用桌面图。背景位置配置现在控制介绍区图片裁切位置。

## 组件与生命周期

2026-09-13 移除生日主题：删除日期自动触发、生日横幅、蛋糕互动、彩纸特效及专用 CSS / JS 和压缩文件，同时清理测试配置与留言种子中的相关内容。已存储的访客留言未作删除。

前台样式加载顺序为基础 `main.css`、共享 `tokens.css`、`bento.css`、`public-system.css`、页面样式。后台通过共享样式片段加载 Token，并将旧组件变量映射到共享变量。新增规则应修改所属组件或页面文件，不再追加另一份主题覆盖层。CSS / JS 修改后同步生成 `.min` 文件。

前后台继续沿用局部导航。文章离开时移除阅读进度的 scroll / resize 监听；预览提示和进度条放在 `main` 内，随内容一起替换。搜索、编辑器及图表保持现有初始化流程，后台主题变化重新绘制图表。

搜索弹窗、移动导航、后台命令弹窗与详情抽屉补充键盘焦点约束和 Escape 关闭，关闭后恢复触发位置。文章和作品提交时同步锁定桌面及移动保存按钮；失败后保留输入并恢复按钮，允许重试。

## 验收方式

常规检查：

```bash
npm run lint
npm test
npm run minify
npm run minify:check
node --check public/js/main.js
node --check public/js/admin.js
```

可选浏览器验收脚本为 `scripts/frontend-v2-qa.js`。运行环境需要能通过 Node.js `require('playwright')` 加载 Playwright，并已安装与其匹配的 Chromium。Playwright 不作为应用生产依赖；使用独立工具环境时通过 `NODE_PATH` 指定模块目录。

```powershell
# 按本机工具环境设置；浏览器和依赖需预先准备好。
$env:NODE_PATH = '工具环境的 node_modules 绝对路径'
$env:PLAYWRIGHT_BROWSERS_PATH = 'Chromium 缓存绝对路径'
$env:QA_OUTPUT_DIR = '验收结果输出绝对路径'
node scripts/frontend-v2-qa.js
```

脚本复制应用到系统临时目录，并为数据库、上传和备份设置独立目录。由于上传中间件根据代码位置计算路径，仅隔离数据库不足以保护用户上传文件，因此应用本身也隔离。脚本不会加载项目 `.env`；使用测试账号和合成内容，结束时关闭浏览器和测试服务器，保留临时目录供排查。输出包含 `report.json`、`server.log` 和截图。

## 验收结果与边界

2026-09-10 本地验收：ESLint、42 项单元与集成测试、资源生成及一致性检查通过。改动前基线为 40 项通过；本次新增 2 项主题控制测试，覆盖系统偏好、手动设置、跨标签页同步及存储不可用情况。现有备份测试在临时目录验证创建、校验、恢复和安全备份；现有集成测试覆盖草稿预览及内容历史恢复。

Chromium 页面矩阵覆盖 12 个前台地址与 22 个后台地址，在 375、768、1024、1440px 下分别检查浅色和深色，共 272 个组合。检查页面响应、主标题、整页横向溢出和页面脚本异常；使用长代码、长表格、缺少封面和空内容样本。共享文字、主按钮及语义状态的 18 组颜色组合最低对比度为 4.79:1。

浏览器交互验证包含登录、搜索及无结果反馈、搜索跳转与焦点约束、作品筛选与历史返回、文章局部切换与代码复制、移动导航、留言提交和审核公开、后台命令导航、审计抽屉焦点恢复、保存失败后重试、文章发布、图片上传、作品保存及空数据布局。代表截图包含桌面与手机的首页、文章页和后台概览，以及无图空首页。

验收边界：

- 浏览器验收使用 Chromium，未执行 Firefox、Safari 或实体手机测试。
- 外部字体请求在隔离测试中被替换为空样式，外部头像与封面使用合成图片；截图验证的是系统字体回退和布局，不包含外部 CDN 可用性。
- 颜色检查针对共享 Token 组合，未逐像素测量所有内容图片和图表，也不代表完整 WCAG 合规认证。
- 未执行生产部署、真实站点数据恢复或真实通行密钥注册；这些操作不属于本次本地交付。

## 验收中修复的问题

长代码曾使后台编辑器撑开整页，现为编辑器容器设置最小宽度约束；平板侧栏曾多出 8px 边距，已移除冲突规则。文章容器重构后遗漏 grid 声明、命令导航后弹窗未关闭、文章局部跳转遗留阅读进度监听等问题均在浏览器验收中发现并修复。相关路径纳入页面矩阵或交互断言，避免只凭样式源码判断结果。

测试服务器原有 10 秒启动等待在并发检查时超时，验收脚本改为最多等待 60 秒，并在进程退出时提前报告日志；该调整只影响验收工具。

### 回收站、媒体库与审计组件补验

用户截图指出了上一轮验收遗漏：回收站和审计的原生输入框没有接入公共控件选择器；审计六个字段使用了五列规则；页面居中规则漏掉筛选栏、媒体工具栏和维护表格，导致大屏下边界错开。整页溢出检查和 Token 对比度检查无法发现这些组件问题，上一轮据此判断界面完成不充分。

本次将筛选框接入 36px 高度、6px 圆角和共享边框、焦点状态，手机控件使用 44px 高度；审计与回收站分别定义列宽，统一页面内容的 1440px 上限与居中轴。媒体工具栏去除搜索框双重底色，统一选择器箭头；上传区增加图标、文件按钮与格式说明层级。回收站、审计与媒体空状态通过 EJS 公共片段复用图标、标题和说明。

浏览器矩阵对这三页增加实际元素边界对齐、控件圆角与高度、下拉箭头和搜索输入透明背景断言，并输出四档尺寸、两种主题的逐页截图。后续组件验收须同时检查页面布局和控件实际计算样式，不能用共享 Token 检查代替组件验收。
